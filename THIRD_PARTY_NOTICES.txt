-------------------------------------------------------------------------------

Standalone binary distributions of RustTracker (Windows installer, macOS `.dmg`,
Linux/SteamOS `.AppImage`, and Android `.apk`) bundle FFmpeg libraries. Because
RustTracker itself is distributed under the GNU General Public License v3.0 or
later (with full corresponding source code publicly available at
https://github.com/Soddentrough/rusttracker), redistributors conveying standalone
packages that bundle FFmpeg libraries should ensure:
  - If bundling LGPLv2.1+ FFmpeg builds, retain FFmpeg copyright/LGPL notices and
    provide or point to the exact corresponding FFmpeg source version used (and
    prefer dynamic linking in desktop bundles so users can relink/replace shared
    FFmpeg libraries).
  - If bundling FFmpeg builds configured with `--enable-gpl` / `--enable-version3`,
    convey the combined distribution under GPLv3+ terms (excluding `--enable-nonfree`
    codecs) alongside the corresponding FFmpeg source code for the bundled build.
