Standalone binary distributions of RustTracker (Windows installer, macOS `.dmg`,
Linux/SteamOS `.AppImage`, and Android `.apk`) bundle FFmpeg libraries. Because
RustTracker itself is distributed under the GNU General Public License v3.0 or
later (with full corresponding source code publicly available at
https://github.com/Soddentrough/rusttracker), redistributors conveying standalone
packages that bundle FFmpeg libraries alongside `libmpeghe` must use **LGPL-only**
FFmpeg builds (`LGPL-2.1-or-later`, built WITHOUT `--enable-gpl` / `--enable-nonfree`),
retain FFmpeg copyright/LGPL notices, preserve dynamic library replaceability (or
provide corresponding FFmpeg source archives), and point to the exact corresponding
FFmpeg source version used. If building RustTracker without `libmpeghe` and bundling
FFmpeg configured with `--enable-gpl` / `--enable-version3`, convey the combined
distribution under GPLv3+ terms alongside the corresponding FFmpeg source code.

7. Rust Crate Dependencies & Bundled UI Fonts (`Cargo.lock`)
-------------------------------------------------------------------------------

RustTracker statically links open-source Rust crates listed in `Cargo.lock`,
including crates under MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC,
Zlib, BSL-1.0, MPL-2.0 (`symphonia*`), Unicode-3.0, and WTFPL, as well as
`epaint_default_fonts` (`(MIT OR Apache-2.0) AND OFL-1.1 AND Ubuntu-font-1.0`,
which embeds Ubuntu Mono/Proportional, Hack, and Noto Emoji font data for
`egui` UI rendering). Exact crate versions and licenses are recorded in
`Cargo.lock`.
